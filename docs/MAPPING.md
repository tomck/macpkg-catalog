# Mapping policy
Exact names, normalized names, and official aliases produce review suggestions. A shared upstream URL may produce an automatic candidate at confidence 0.97 only when it identifies a unique target within that manager. Multiple variants sharing the same upstream remain under review. Curated relationships require evidence and may be automatic at confidence 0.9 or higher.

Descriptions and fuzzy spelling must never produce automatic mappings. Those suggestion tiers and provides/replaces inference are not yet implemented. Automatic does not authorize package installation: consumers must verify local availability, compatibility, and user intent.
